Build mode = the L3 workflow surface: live fleet, phase progress, tdd+review gates, per-task worktrees, parallel race ③ when a task is forked. Its own keymap (j/k navigate tasks, o open worktree, p pause). esc or :chat drops you back into Chat, which kept running underneath.

the paradigm

Modes are the top-level navigation. v1 ships Chat + Build. Switching is manual (F2 / :build / :chat) or agent-suggested — never silent. The shared event log means a finished Build leaves a collapsed summary card in the Chat transcript (re-expandable via ① zoom). Later, new modes slot in as peers — e.g. Canvas (② branch map) or Review — without disturbing these two.
