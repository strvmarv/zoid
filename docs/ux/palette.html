Two entry points: ^P opens the fuzzy, mode-aware palette — grouped (mode · branch · navigate · context · settings · recipes), each row showing its keybind so you learn shortcuts by using it; results rank by recency + match. : is the direct command line for power users. The palette surfaces global verbs (switch mode, settings) plus actions relevant to the current mode. Mode-switch (:build / :chat) lives here and on ⇧Tab.
