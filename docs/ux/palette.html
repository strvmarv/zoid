One adaptive palette (^P). Empty query: fuzzy, mode-aware list — grouped (session · mode/app · navigate · context ⑤ · settings), each row showing its keybind so you learn shortcuts by using it; results rank by recency + match. Type : as the first character to switch the same prompt to direct-command mode: live-preview the parsed command, ⏎ runs it. The palette surfaces global verbs (new/resume session, quit, settings, delegate, import mode, drawer toggles) plus current-mode actions — and since rail drawers carry no keybinds for now, it's how you toggle them. (Switch to Build is deferred until the autonomous loop is built.)
