What the Rust base unlocks for the UX

Four capabilities that were impractical on the old stack and are natural on Rust (ratatui immediate-mode + graphics-protocol images + tree-sitter + GC-free redraw). They layer onto Chat/Build. Multi-select what excites you; note v1 vs later in the terminal.

Ⓡ1 · Inline raster graphics Kitty / Sixel

Unlocks: the churn timeline ⑤c, the session/branch map ②, and dependency/plan graphs can render as **actual pixel images** inline — crisp charts, diagrams, even rendered-markdown figures — on terminals that support the graphics protocols (Kitty, WezTerm, iTerm2, Sixel). Graceful fallback to ASCII sparklines where unsupported. (Mostly POST-V1 polish, but designing the renderer with a pluggable "image-or-ASCII" backend is a v1 decision.)

Unlocks: because immediate-mode redraws a fresh buffer each frame with **no GC pauses**, zoom can *animate* (turns visibly fold/unfold), drawers **slide**, mode-switches **transition**, streaming has a smooth caret, and the Build fleet shows **live motion**. Most TUIs feel "steppy"; zoid can feel fluid — a signature polish that's hard to copy. (A motion budget + reduced-motion setting; v1 can ship a few key transitions.)
