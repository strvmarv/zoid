# P4b · Ⓡ2 Motion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the Ⓡ2 motion substrate — pure easing/interpolation primitives, a `reduced_motion` setting, and a frame-tick loop that animates only while something is moving — and prove it end-to-end with a streaming-caret blink.

**Architecture:** Motion splits cleanly into a **pure layer** (`crates/zoid-tui/src/motion.rs`: easing, `lerp`, an `Anim` progress type, a `caret_on` blink — all `f32`/integer math, fully unit-tested incl. the reduced-motion correctness case spec §13 requires) and an **impure shell** (the `zoid` bin owns the `std::time::Instant` clock + a third `tokio::select!` arm). The "motion budget" is the select arm's guard: the tick branch is **disabled unless an animation is active** (`app.streaming`), so an idle app blocks on real events at zero CPU. P4b's one live consumer is the streaming caret; the richer consumers (zoom fold/unfold) arrive in **P4c**, which depends on this crate.

**Tech Stack:** Rust 2021, `tokio` (`time` feature — already enabled in `[workspace.dependencies]`), ratatui 0.29, `std::time::Instant`.

## Global Constraints

- **Crates & dep direction:** pure motion math lives in `crates/zoid-tui/src/motion.rs` (no clocks, no ratatui state); the `Instant` clock and the tick loop live **only** in the `zoid` bin (`crates/zoid/src/main.rs`). `reduced_motion` is a field on `ShellState` (pure interaction state). Never put wall-clock reads in `zoid-tui` or `zoid-core`.
- **Motion is NOT snapshot-coverable (spec §13):** do **not** add `insta` snapshots that depend on an animation frame. Motion is verified by (a) **pure unit tests** on the math, (b) the **reduced-motion correctness test** (with reduced-motion on, a transition resolves to its final value immediately), and (c) manual/gif review. Existing snapshots must stay green — when `render_shell`/`conversation_lines` gain the `caret_on` param, callers in tests/preview pass `true` (steady caret), so no snapshot churn.
- **Motion budget = no idle ticks:** the tick `select!` branch carries an `if app.streaming` guard; when no animation is active the branch is disabled and the loop waits on terminal/agent events only. Add a named `MOTION_FPS` const — do not hardcode the interval.
- **Reduced-motion is honored everywhere motion is read:** `reduced_motion` short-circuits every animated value to its resting/final state. Default **off**; the bin reads `ZOID_REDUCED_MOTION` (any non-empty value → on) at startup. No config-file system (none exists — YAGNI).
- **Design tokens (spec §16):** the caret uses the existing `glyph::CARET` / `color::CHAT_ACCENT`; no new glyphs or hex. No new visual tokens are introduced by P4b.
- **TDD, DRY, YAGNI, frequent commits. No `Co-Authored-By` / co-author trailer** (user global instruction).
- Run `cargo test --workspace` and `cargo clippy --all-targets` clean before every commit.

```rust
//! Ⓡ2 motion — the pure math layer (easing, interpolation, animation progress,
//! caret blink). No clocks, no rendering: the `zoid` bin owns the `Instant`
//! clock and feeds elapsed milliseconds in. `reduced_motion` short-circuits
//! every animated value to its resting/final state (spec §13).

/// Frames per second for the bin's motion tick. The tick only runs while an
/// animation is active (the select-arm guard), so this is a ceiling, not a
/// steady draw rate.
pub const MOTION_FPS: u64 = 30;

/// Linear interpolation with `t` clamped to `[0, 1]`.
pub fn lerp(a: f32, b: f32, t: f32) -> f32 {
    a + (b - a) * t.clamp(0.0, 1.0)
}

/// Ease-out cubic: `1 - (1 - t)^3`, clamped. Fast start, gentle stop.
pub fn ease_out_cubic(t: f32) -> f32 {
    let t = t.clamp(0.0, 1.0);
    1.0 - (1.0 - t).powi(3)
}

/// A running animation as elapsed/duration milliseconds.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Anim {
    pub elapsed_ms: u32,
    pub duration_ms: u32,
}

impl Anim {
    /// Linear progress in `[0, 1]`. Returns `1.0` immediately when
    /// `reduced_motion` is set or the duration is zero (no division).
    pub fn progress(self, reduced_motion: bool) -> f32 {
        if reduced_motion || self.duration_ms == 0 {
            return 1.0;
        }
        (self.elapsed_ms as f32 / self.duration_ms as f32).clamp(0.0, 1.0)
    }
}

/// Whether the streaming caret is visible this instant. Steady-on under
/// reduced-motion (or a zero period); otherwise on for the first half of each
/// `period_ms` window.
pub fn caret_on(elapsed_ms: u64, period_ms: u64, reduced_motion: bool) -> bool {
    if reduced_motion || period_ms == 0 {
        return true;
    }
    (elapsed_ms % period_ms) < period_ms / 2
}
```

In `crates/zoid-tui/src/lib.rs`: add `pub mod motion;` and `pub use motion::{caret_on, Anim, MOTION_FPS};`.
