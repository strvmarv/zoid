Build: executes the plan one task at a time, in dependency order — a fresh subagent per task in its own worktree (T3 active; T4 queued). Each task self-gates (tdd → spec-review → quality-review → fix) and merges to the build branch autonomously — you're never prompted to approve a merge; only a blocker stops for you. Two wide panes (overview · stream) + the mode-aware rail (economy · changed-files · steering). In changed-files, ⚠ marks a file touched by more than one task (informational). Selecting a task with j/k filters the tree to it; ^Z zooms any pane full-screen.
